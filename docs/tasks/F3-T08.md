rates, historical graphs and exact-value pages. Ordinary navigation must not wait
for background preparation. Keep user-visible missing/stale/partial/expired states,

## Implementation

- Separate live, interactive and derived database admission; bound workers,
  retries, shutdown and retained work without sacrificing live capacity.
- Maintain source aggregates, current summaries and retained SLO points/tiles
  independently of page visits. Preserve usable results and truthful provenance
  while repair/backfill proceeds.
- Assemble bounded graph summaries and exact edges; retain numeric extrema and
  explicit incomplete/gap coverage. Do not sweep a year of canonical observations
  or rebuild all objectives for a ready list/detail request.
- Store encoded tile summaries and immutable response metadata. Match response
  identity/generation/range before validating its payload digest, avoiding work on
  unrelated cached graphs. Migrations 0037–0040 supply the retained metadata.
- Page lists and pin global counts/exact tables to coherent generations. Account
  admission by actual work/bytes rather than recent completed navigation count.
- Share/cancel browser reads and keep independent sections usable. Preserve the
  retained visual reference and existing renderer; ADR-0026 remains proposed.
- Complete browser export flushing and release unused upload response bodies.
  These fixes preserve backend telemetry destinations, authentication and quotas.
