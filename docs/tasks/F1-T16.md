## Outcome and boundaries

Support `almanac serve --components=backend,ui` and the equivalent `ui,backend`.
Serve the existing embedded production assets and real authentication API on the
same listener, with the existing TLS/trusted-termination, provisioning, readiness,
database ownership and shutdown lifecycle. This is the runtime prerequisite for
browser onboarding, not its screens. No frontend source changes, alerts, agent,
management routes, new dependency, schema or authentication protocol changes.
The default component set includes alerts and must still fail before listening;
never silently omit an unsupported selected component. UI-only serving remains
available as before; secure remote UI authentication integration is separate work.

Coordinator choice within ADR-0008: use the backend-owned listener and health
representation (`component: backend`) for this combined pair. Static assets have
no independent worker or readiness state; load their handler before provisioning
or binding. This preserves existing health schemas and backend lifecycle semantics.
Do not proxy combined API requests to a second listener or consult backend_url.
