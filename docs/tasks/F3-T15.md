# F3-T15: SLI measurement history ranges

- State: review
- Branch: `codex/sli-measurement-ranges`
- Governing guidance: [SLI measurements](../specs/0012-user-interface.md#sli-measurements), [ADR-0046](../adr/0046-sli-measurements-and-collection-detail.md)
- Authorization: the maintainer requested a fast range picker with a small backend change, then requested a PR and screenshots for all six ranges.

The SLI measurements panel offers 1h, 3h, 6h, 24h, 7d and 30d. The default uses
exact intervals. Longer ranges group canonical observations into at most 240
buckets in a single PostgreSQL query. Each bucket carries exact good and total
sums and distinct collection outcomes. The original exact-interval table keeps
its cursor. The change adds no migration, collection work or preparation job.
