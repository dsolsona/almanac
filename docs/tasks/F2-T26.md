## Outcome and scope

Provide readable credential durations, session-authorized lifecycle controls and
dependency-aware agent deletion. Consume the generated agent management contract.
Backend, API generation, authentication screens and launcher are separate tasks.

## Acceptance

- Register “Local agent” with the 90-day default, correct invalid custom input,
  and navigate to its details. Rotate with a 10-minute default or immediate grace.
- List every assigned datasource by name and link, offer replacement registration,
  and prevent deletion until refresh confirms no assignments. Errors cannot enable it.
- Confirm deletion, return to the list and retain safe retry behavior for uncertain
  outcomes and stale versions. No lifecycle action asks for a current password.
- Inspect keyboard, mobile and both themes against the accepted reference. Exercise
  the complete path through the real isolated Compose deployment and database.
