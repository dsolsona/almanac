## Design and scope

Extend actual shared exports and their local catalogue examples. Preserve all
palette/font/theme tokens. No new dependencies, backend behavior or feature screens.
Use a custom styled month grid inside the existing native Dialog, instead of an
OS date popup whose appearance cannot match the catalogue. Use native checkbox
semantics for switches and CSS transform animation for indeterminate loading.
Date values are calendar dates, not timestamps; scheduling/timezone semantics are
outside this task. This is a routine extension under the accepted UI architecture.

## Interfaces and behavior

- `Switch`: native input attributes except type/role, plus label/hint. Native
  checkbox with role=switch, visible stable label and On/Off text, associated hint,
  keyboard Space activation, checked/unchecked/disabled examples. Teal checked
  track, neutral unchecked track, visible focus and thumb position independent of
  color. Native form/change semantics; no delayed state change.
- `DatePicker`: label, value (YYYY-MM-DD or empty), onValueChange, hint, disabled,
  optional today input for deterministic examples/tests. Trigger opens shared Dialog
  and focuses selected day or today. Labelled month grid with Monday-first weekdays,
  month navigation, today marker distinct from selection, previous/next controls,
  Clear and Cancel. Navigation does not commit; day click/Enter/Space commits and
  closes; Escape/Cancel preserves value and restores trigger focus. Disabled never
  opens. One tabbable day, arrows move day/week, Home/End move week bounds,
  PageUp/Down change month with day clamping; Shift changes year. UTC arithmetic
  avoids DST shifts; validate real dates and years 0001–9999. Reject invalid values
  as dates, do not normalize impossible dates silently. Adjacent out-of-range years
  are disabled. Preserve visible focus after month transitions. Responsive grid
  must fit360px with no horizontal overflow.
- `LoadingIndicator`: accessible labelled indeterminate status; no fake percentage.
  Teal moving segment using transform-only continuous linear animation (~900ms),
  no easing pauses/bouncing width calculations or JavaScript animation timer.
  Reduced-motion preference shows a static indicator plus text. Shared export
  replaces native progress in loading example. Use same indicator/visual language
  for pending button decoration where appropriate without duplicate live announcements.
- Save demo starts immediately and exposes an explicit "Finish local example"
  control while pending; remove the artificial700ms timer. This intentionally
  demonstrates pending/completion without making a local action feel slow.
