## Outcome and boundaries

An internal, unwired compiler captures finite maintenance revision R, retains its
inputs, replays raw events into durable membership, seals membership and produces
an immutable union with exact cumulative coverage. Partial or missing history is
never readable as a completed mask. Historical R remains complete even if current
authority advances. No current promotion, runtime registration, public routes,
calculator consumer, production batch/lease defaults or release claim.

Genesis revision zero is the only replay baseline. Membership checkpoints,
union-equivalence reuse, cleanup scheduler, compatibility indexes, adjusted hours
and adoption/performance gates remain later work. Existing observations and
numeric derived evidence are unchanged.

## Interfaces and storage

Private transaction-scoped functions in `maintenance_compiler*.go`:

- `captureMaintenanceBuild(ctx, tx, sloID, requestedRevision *int64, now)` captures
  current R when nil; an explicit historical R must be between zero and current.
- `claimMaintenanceBuild(ctx, tx, buildID, leaseDuration, clock)` returns an opaque
  lease token. Caller supplies positive lease <=5 minutes; no runtime default.
- `advanceMaintenanceBuild(ctx, tx, claim, pageLimit, clock)` processes one raw
  replay OR one sealed-member page. Limit 1..1000 is a defensive implementation
  ceiling, not an adopted production throughput value. Sample time after row
  locks and immediately before return; an expired lease must roll back the turn.
- `readMaintenanceCoverage(ctx, q, buildID, start, end)` requires complete state
  and returns SLO/revision identity, excluded microseconds and latest eligible
  endpoint using two indexed predecessor seeks. Caller uses its source snapshot.

The caller owns transaction commit/rollback; an error requires rollback and no
further work is permitted between the final fence and commit. Tests exercise the
actual transaction boundary. Invalid inputs and stale ownership are distinct from
retained-history unavailable. No implicit retries.

Migration `0062_maintenance_compiler.sql` adds build, per-SLO deletion guard,
staged membership and union tables. SQLC source `query/maintenance_compiler.sql`
and generated corresponding query/models/interface files are owned. `sqlc.yaml`
adds missing 0060 and dependency 0061 before 0062. Dependency migration/docs copies
are excluded from handoff.

A build pins all events `(0,R]` until explicit cancellation or future deletion;
completed snapshots continue to retain their original provenance. Each membership
row references immutable declaration revision and its explicit SLO scope. Source
revision FKs retain immutable reason/actor/audit data. A deletion trigger refuses
pinned event/scope removal. A dedicated per-SLO guard row is actually updated both
on capture and source deletion, so stale repeatable-read cleanup aborts rather
than relying on a lock with unchanged row version. Capture follows existing order:
SLO root, exclusion state, deletion guard, then build; existing writers take root
and state in that order. Compiler turns lock only their build; they never acquire
maintenance identity/root locks afterward. Lease loss retains pins.

Replay SQL applies LIMIT to raw `(slo_id, revision > cursor AND revision <= R)`
before declaration lookup. Require cursor+1 at each event and reject missing
referenced bounds/scope; removals advance cursor. Membership mutation and cursor
commit atomically. Seal only at exact R. The second pass uses
`(build_id, starts_at, exclusion_id)` keyset, one open union interval and cumulative
microseconds. Adjacent/overlapping windows merge; each raw member advances the
cursor. Completion publishes the final frontier in the same fenced transaction.
Completed coverage cannot be updated by the compiler, and partial rows are hidden.

Bounds follow existing maintenance authority: UTC whole seconds, years 1970..9999,
strict start<end. Coverage uses Unix-microsecond differences and int64 cumulative
microseconds (full supported timestamp span fits); it never casts large windows
to Go time.Duration. Empty masks return zero coverage with end eligible. If the requested end lies within a union, latest eligible endpoint is the
global union start, even before the request start; this matches the raw mask
and F4-T43 coverage ranks. No claim of an eligible observation is made. Zero/inverse/subsecond/non-UTC inputs are invalid.
