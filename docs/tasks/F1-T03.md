## Outcome

Reusable aligned timeline charts and paginated exact-value tables, demonstrated
with explicitly synthetic catalogue data. No SLO calculation, API, scheduling,
event/maintenance persistence or domain screens. Annotation/maintenance overlays
and the full SLO workload benchmark remain subsequent work. Chart presentation
must not imply that missing observations were successful.

## Design and interfaces

- Use ECharts 6.1.0 (registry verified, Apache-2.0), modular imports from core,
  charts, components and SVGRenderer; no full-package import or React chart wrapper.
  Pin lockfile with explicit setup. Existing package versions remain pinned.
- New shared exports live in web/src/components/charts/. Separate model validation,
  ECharts option generation, React instance lifecycle and exact-table rendering.
- `TimelinePoint`: timestamp UTC ISO string, value decimal string or null, coverage
  complete/partial/missing/zero-traffic. Value is already in the lane's display unit;
  the component never computes SLOs, percentages, budgets or burn rates. Preserve
  exact strings in tables and tooltips; convert only for plotting.
- `TimelineSeries`: id, label, points. `TimelineLane`: id, label, unit, series
  (maximum2). `TimelineChart`: title, summary, start/end UTC timestamps, stepMs,
  lanes (maximum4). Range is [start,end); samples sorted strictly, no duplicate
  timestamps. Validate finite values, valid timestamps/range, positive step,
  coverage/value consistency, and enforce1500 plotted points per series including
  any inserted gap sentinels. Reject unsupported/oversized input visibly with a
  useful error; never silently truncate or average. No values for missing or
  zero-traffic; partial values stay labelled partial and are not plotted as complete.
- One ECharts instance renders aligned stacked lanes with identical time grids,
  a single labelled bottom axis and linked crosshair. Explicit nulls and skipped
  expected steps break lines (`connectNulls:false`); zero remains numeric zero.
  Tooltips use exact available sample values at the inspected timestamp, never
  carry old values forward across gaps. Short ranges show time-of-day in UTC.
  SVG options unit-tested for bounds, aligned axes and missingness; browser asserts
  actual SVG output and hover feedback. No test-only instance attached to window.
- Chart has accessible title/summary and visible range, UTC timezone, units and
  coverage explanation. Chart updates/theme changes reuse its instance; observe
  resize and root theme class, dispose instance/observers on unmount. Disable
  chart animation for crisp telemetry; consume existing semantic tokens. Avoid
  rerendering graph when unrelated local controls change (stable fixture props).
- `ExactValuesTable` is a semantic captioned table in a labelled focusable scroll
  region. Controlled props: rows (max50), page (1-based), totalRows, onPageChange.
  Rows contain timestamp, lane label, series label, unit, exact value string/null,
  coverage. Previous/Next native shared Buttons, correct disabled bounds, row count
  and page indicator. Reject >50 rows/invalid page metadata instead of silently
  omitting values. Do not load/slice an unbounded source inside the component.
  Preserve decimal precision such as99.970000 and explicit0.000000. Show distinct
  missing/partial/zero-traffic labels. Table and chart use the same sample objects
  and range in the catalogue; no independently invented table values.

## Catalogue and bundles

Lazy-load a Charts section only when selected/opened, using a small catalogue
loader. Non-chart catalogue controls should not request ECharts. Demonstrate four
lanes (SLI %, budget %, burn x, coverage %) on one common illustrative range,
including a numeric zero, precise decimals, a null gap, a skipped timestamp,
partial and zero-traffic cases. Use at least51 exact rows to exercise pagination.
Explain fixtures are illustrative and contain no live calculations. Include
empty/error/stale presentation examples without marking stale results healthy.
No chart modules, fixtures or route enter the production app shell.
