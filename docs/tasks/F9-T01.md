## Interfaces and edit scope

1. In both point-publication queries, set the hourly tile work's `next_attempt_at`
   to `GREATEST(published_at, start_at + interval '1 hour')`, matching the daily
   rule. `ReadRetainedParts` already treats an hour with pending work as not ready,
   and `retainedSeriesReader.loadPart` already serves the last hour from points, so
   reads are unchanged. Keep `publishRetainedRepairTiles`, which publishes complete
   hours directly.
2. Delete from production; preserve independent raw calculation oracles in test-only files:
   the `input.Runtime == nil` branches of
   `ReadSloOperationalDetail` and `materializeSloOverviewSnapshot`;
   `loadOverviewCandidates`, `loadOperationalDefinitions`, `buildOverviewItem`,
   `buildOverviewSparkline`, `operationalStream`, `operationalDefinition`;
   `buildOperationalSamples`, `buildRollingBuckets`, `sampleBucket`,
   `buildAttainmentSamples`, `buildDailyCompliance`, `clipOperationalFacts`,
   `loadOperationalFacts`, `operationalFactsStart`; `derived_blocks.go` and the
   `displayCache` field; the `detail` kind in `prepareHistory` (overview jobs stay);
   Delete obsolete display-cache-specific tests. Keep raw-oracle comparisons against
   maintained reads without reintroducing application fallbacks. Remove
   the queries `ListOperationalSloDefinitions`, `ListOperationalSloFacts`,
   `ReadReusableSloBlocks`, `UpsertSloDisplayBlock`. Keep `DeleteExpiredSloDisplayBlocks`
   until F9-T03 drops the table. Regenerate with `make shell CMD='make generate GENERATE_MODE=sqlc'`.
3. Keep `slo.WindowSweep`, `evaluateOperationalAt`, `operationalSample`,
   `operationalValue`, `burnValue`, `operationalComplianceDay` and
   `dailyComplianceStatus`: the retained reader and current refresh use them.
4. Allowed paths: `internal/storage/**`, `internal/storage/query/**`, generated
   `internal/storage/dbgen/**`. No migrations, no `api/`, no `web/`.
