## Outcome and scope

Wrap policy registration, global acknowledgement, disable and exhausted-work retry
in real authenticated storage transactions. Reuse current role/session locks,
completion reauthorization, strong resource versions, actor-scoped serialized
command keys, atomic audit and immutable replay responses. Viewer can read;
Editor/Administrator can mutate. Return only policy/occurrence evidence, never
datasource queries or credentials.

The caller supplies first activation boundary, exact admission limits and receipt
lifetime explicitly. Public activation/default choices remain a later source
contract. An existing expired command key returns explicit expiry, never silently
reexecutes. Actor-scoped result lookup distinguishes unknown from expired/success;
unknown does not prove a lost request failed. No HTTP/CLI route is introduced here.
Read original/latest immutable evaluation evidence with its digest, scheduling
time, effective cutoff and commit time. Preserve original policy/SLO names and
actual SLO identity; never reconstruct original evidence from current facts.

## Acceptance

- Real session creates one policy and one audit. Same key/body returns original
  result despite later state; changed body conflicts without side effects.
- Successful acknowledge receipt replays its original globally acknowledged
  occurrence even after recovery. A fresh stale key/version cannot acknowledge
  a replacement occurrence.
- Viewer reads but cannot mutate or replay mutation; revoked/expired/restricted
  sessions cannot read/replay. Recheck after lock waits and at completion.
- Audit or receipt failure rolls back every mutation. Concurrent same-key calls
  serialize; no duplicate policy/transition/audit.
- Disable/retry preserve their existing cancellation/failure fences and evidence.
- Lookup remains actor-scoped, with no invented failure for an unknown key;
  expired keys cannot cause a second mutation.
