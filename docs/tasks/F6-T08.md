## Outcome and non-goals

The approved proposal mocks ([docs/design/mocks/proposals](../design/mocks/proposals/README.md))
applied to the datasource, agent, SLI and SLO lists and their detail pages:
- **Heads:** title and the one primary action on one line; no count subline and
  no "Updated" line.
- **Toolbars:** one row with filter pills and a quiet icon refresh at the end.
- **Tables:** name-first rows with health chips; "UTC" in the time column
  header; the datasource Agent filter and Auth column are removed.
- **Agents:** the title row carries the agents actions; Register agent only on
  the list.
- **Details:** a breadcrumb line on every detail page; button roles on detail
  actions, with rotate as primary and destructive triggers as danger outline.
- **Credentials:** one row per agent token.
- **Shared controls:** `RefreshButton`, `FilterSelect`, `ToolbarSpacer`,
  `StatusChip`, and the `link` and `danger-outline` button variants; shown in
  the catalogue and documented in the design guide.

Not in this task: folding revoked and expired credentials (shown in the mock),
the "Last query" datasource column (needs a list projection, already deferred),
and running the long real-stack journeys (the maintainer asked to run them only
on request); their verifiers are updated to the new markup.

## Implementation evidence

- Unit suite 384 passed (macOS host entry into the dev container); ordinary
  gate 384 web, 509 Go and 31 tooling cases; browser matrix 132 passed on the
  final tree; typecheck clean.
- Tests updated where the contract changed:
  - Refresh buttons have specific names ("Refresh SLOs", "Refresh SLI").
  - The SLO status reads from the chip.
  - The datasource list asserts name-first columns, no count line, no Agent
    filter and agent-name search.
  - Credential rows are list items whose dates carry the exact values in their
    tooltips.
  - Registration starts from the list.
  - Two tests wait for the session check to enable Register agent before
    clicking.
- Defect found and fixed during the change: the agents actions first looked up
  their title slot in the DOM once. If the shell attached the slot later, an
  inline copy was swapped out mid-click and the Register dialog never opened.
  The shell now owns the slot through a callback ref and passes it as a prop.
- Catalogue renders checked in light, dark and 390 px: the refresh icon needed a
  selector that beats the generic button padding, and the page head's heading
  margin was removed so the toolbar sits 20 px below.
- Not run: the long real-stack journeys (integration, Compose), at the
  maintainer's request. Their verifiers are updated to the new markup (SLI and
  SLO refresh names, the SLO count line, credential list items) but are
  unverified until the next journey run.
