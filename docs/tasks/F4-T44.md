## Outcome and interface

Add an unwired read adapter accepting a caller-owned repeatable-read transaction,
expected SLO/build/exclusion revision, and paired window inputs/totals. Authenticate
complete build identity and persisted SLO cadence in that snapshot. Historical R
remains readable after authority R+1. The caller still owns source-fact identity,
admission, retained snapshot references and final publication fencing.

Expose `slo.RequiredCoverageAnchors(input, totals, latest)` from shared boundary
logic and use it in both certificate validation and storage. Never duplicate
validity, retention or observation rounding in the adapter. Preserve all raw and
aggregate calculation rules; no production consumer or schema change.

## Concrete implementation and acceptance

1. Fail focused helper/real PostgreSQL tests before implementation.
2. Refactor the exact anchor construction and input-time checks into a pure helper.
   Invalid observations cannot panic; at most nine sorted distinct anchors.
3. Reject mismatched lengths and more than the existing 960-window batch limit.
   Read complete scoped build plus current SLO cadence. Reject incompatible grids.
4. Resolve distinct ends with one array/lateral indexed predecessor query. Derive
   global latest eligible endpoints, including before requested windows. Resolve
   all distinct remaining anchors in a second bounded batch. Convert cumulative
   microseconds to exact whole cadence counts, rejecting fractional ranks.
   A previous anchor before 1970 is rank zero, not fabricated retained evidence.
5. Real immutable build tests compare rank-backed shared results against an
   independent raw interval oracle on 60/70-second grids; include historical R,
   full exclusion, clipped validity/retention, mixed outcomes, missing/incomplete
   builds, scope/revision/grid mismatch, cancellation, caps and indexed plans.
6. Run only focused Docker unit/race integration checks and SQLC generation.
   Retain first failures and exact commands/durations. Structural EXPLAIN proves
   available seek bounds, not production planner or fleet latency acceptance.

## Verification and evidence

The new helper and adapter tests first failed to compile because their interfaces
were absent; these are preserved as interface reds, not claimed database behavior
failures. After implementation, the first pure race selection passed in 1.062 s
and the historical-R PostgreSQL case passed in 1.529 s. Expanded PostgreSQL checks
passed in 3.363 s. Final frozen selections:

```sh
make shell CMD='make generate GENERATE_MODE=go-guidelines'
make shell CMD='make generate GENERATE_MODE=sqlc'
make shell CMD='go test -race ./internal/slo -run "TestRequiredCoverageAnchors|TestCovered" -count=1 -json'
make shell CMD='go test -race -tags=integration ./internal/storage -run TestIntegrationMaintenanceCoverage -count=1 -timeout=5m -json'
```

Final race results: 87 pure test/subtest cases, 1.072 s; 15 PostgreSQL test/subtest
cases, 3.994 s. The PostgreSQL selection covers real compiled history at R after
R+1, 60/70-second independent raw-oracle equality, overlap, partial/empty/failed/
zero observations, expired and unaligned eligibility, full-window exclusion,
pre-1970 predecessor rank at genesis, missing and unavailable builds, identity
and grid rejection, RR publication consistency, cancellation and the 960 cap.
Empty input performs no SQL; it does not certify a build identity.

A recording transaction verifies 960 identical windows use three queries with
one unique end and two remaining anchors. EXPLAIN of the actual generated query
uses the coverage primary key backward scan and LIMIT 1 (two index searches for
two anchors). This small-fixture check explicitly disables sequential scans to
prove an available bounded path; it is not default planner or capacity evidence.
No operator fixture, runtime registration, broad suite or workload was run.

The adapter validates geometry and persisted mask identity. The shared totals
consumer remains authoritative for numeric/count/quality consistency; obtaining
a certificate alone does not certify the supplied numeric population.

Owned changes are the new anchor helper/tests, narrow coverage validator refactor,
new storage adapter/three integration test files, new SQL/generated query file,
two generated querier entries and this task. Copied compiler/math/schema/fixture
