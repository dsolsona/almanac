## Outcome and non-goals

Observations live in `almanac_sli_observations` with the primary key in access
order and no stored interval end; the ingestion function marks the source
generation, dirty hour and extrema (or repair) cursor explicitly; both triggers
and the two old tables are gone. No change to any value shown to a user.

## Required context

ADR-0041; `internal/storage/sli_ingestion.go`, `migrations/0013`, `0022`, `0026`,
`0032`, `0041`, every query touching `almanac_sli_coverage` or
`almanac_sli_observation_values` (`grep -l` in `internal/storage/query`),
`retention_worker.go`, `retention.go`, `derived_metrics.sql`.

## Interfaces and edit scope

- Migration (next free number): create the table and partitions for every
  existing month, the partial observed index; copy coverage joined to values
  partition by partition with per-partition count and value verification; drop
  the old tables, both triggers and their indexes after verification. Resumable:
  idempotent copy keyed by the primary key.
- `IngestAgentObservation`: one insert; then explicit generation increment,
  dirty-hour upsert with the existing attempt reset, and cursor widening, in the
  acceptance transaction; duplicates and conflicts mark nothing.
- `prepareSliPartitions`: one table. Retention partition handling: one table.
- Every query rewritten against the new table; `interval_end` computed from the
  cadence where needed.
- Allowed paths: `internal/storage/**`, generated sources.

## Acceptance and expected cases

- Accepting an observation produces exactly the generation, dirty-hour and
  cursor effects the triggers produced, verified by comparing table state before
  and after against the pre-change build on the same fixture.
- A duplicate or conflicting delivery changes nothing.
- All existing integration tests on ingestion, aggregates and retention pass.
- Migration rehearsal on a copy of the preview database: row counts and values
  match per partition; current statuses match; old tables are gone.
- A revision with 200,000 rows migrates in bounded transactions under the 5 s
  statement timeout.

User acceptance checklist:

- Expected: SLI and SLO pages unchanged; collection continues.
- Container journey: `make test-e2e`.
