## Outcome and non-goals

The agent list and agent detail match `docs/design/mocks/agents-list.html` and
`agent-detail.html` using today's API. Registration, token disclosure, rotation,
revocation, disable and delete keep their dialog contract, command keys,
uncertain-outcome recovery and session rechecks unchanged.

List: the shell title stays; under it a mono summary (agents, connected,
unreachable, never connected, disabled), Updated, Refresh, Register agent; a
filter of the loaded page and status segments (All / Needs attention /
Disabled); the table with Status (ADR-0028 agent vocabulary from the record and
its runtime), Agent (identifier button, display name, version, since) and
Collection; the shared pager with URL cursors.

Detail: the shell title becomes the agent's display name; status line, mono
meta (identifier, protocol, version, registered, datasource count), Updated,
Refresh, How to run, Rotate credential, Register agent; unreachable and
disabled banners; Connection / Configuration / Collection / Credential tiles;
Datasources card from the agent's bounded datasource read with a move link;
Credential history card with a state mark per credential, the exact timestamps
and Revoke; Runtime details collapsed under a disclosure (unchanged panel);
a danger line with Disable and Delete. The How to run dialog shows the two
documented start methods (`make agent`, the built binary with `--token-file`)
with this backend's origin.

**Deferred and flagged: registration as a page** (`agent-register.html`,
ADR-0028 and plan 0025). The one-time token disclosure, the uncertain
registration intent, the abandon prompt and the 40-plus unit cases are built on
the registration and token dialogs; moving them to a three-step page with the
live checklist changes that contract and needs its own task with the
maintainer's go-ahead. The dialog stays; step 3's content is available from the
detail's How to run dialog. Also deferred per the mocks README: the heartbeat
strip, query success ratios and credential expiry on list rows, datasource
names on list rows (needs a list projection; the detail reads them).

| Condition | Tone | Label · reason |
| --- | --- | --- |
| disabled | none | Disabled · by administrator · date |
