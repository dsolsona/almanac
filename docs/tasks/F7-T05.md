## Outcome and non-goals

The suite in ADR-0033:
- `make test`, `make test-integration`, `make test-browser`, `make test-e2e`, `make test-perf`,
  `make check` and `make coverage`.
- CI on every pull request.
- The old runner, custom browser scripts and performance harness deleted.

Not in this task:
- Web coverage, which needs the `@vitest/coverage-v8` dependency.
- Permission-failure journeys, which wait for multiple users.

## Evidence

- **Gates:** `make test`, `make test-integration` (with and without `RACE=1`), `make test-browser`
  and `make test-e2e` pass on the integrated tree.
- **Go journeys:** the agent runtime journey passes in 35 s, down from 64 s. The objective journey
  passes in 22 s, down from 66 s. The SLI collection journey passes in 21 s, down from 28 s.
- **E2E disk check:** usage inside the VM was 25 GB before and after the run, and no `almanac-e2e`
  volumes remained. The closing trim brought Colima's disk file from 31 GB to 25 GB, and the Mac went
  from 14 GB to 19 GB free.
- **Findings while writing the journeys:**
  - VictoriaMetrics hides the newest 30 s from queries, so the preview sample is stamped a minute ago.
  - A local agent shares the app's network namespace, as `make agent` does, so it is restarted after
    the app.
  - Forms preselect the only agent or datasource.
  - Decimal good counts left 4 of 20 performance SLIs without an observed interval, so the fixture
    uses whole counts.
  - A single SQL call for 35 days of history exceeded the 120 s command limit, so history is written
    one day per call, at about 4 s per day.
- **Disk incidents on 2026-11-05:** the performance seed, then writing to a Docker volume, filled the
  host disk twice and gave Colima I/O errors. The maintainer freed space and restarted Colima. The
  tmpfs overlay and the disk guard above prevent a repeat.
- **Open investigations, kept as recorded:**
  - An early single-process run of the storage package failed once and has not recurred. Its cause is
    unknown.
  - The parallel run's browser agent-lifecycle failure ("body_read_failed") was in a script that is
    now deleted. The F3-T08 investigation of that class stays open.
