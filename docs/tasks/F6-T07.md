## Outcome and non-goals

Maintainer review of the merged screens on 2026-11-05:

- The agent registration and rotation expiry controls follow the approved
  agent-register mock: preset chips (30 days, 90 days, 1 year) with a "Custom…"
  chip in whole days, and the grace control as chips (Immediately, 1, 5 and
  10 minutes) with custom whole seconds. The dropdown and unit selector are gone.
- Form section cards, page heads, banners and tiles had no spacing: they used
  `--space-5`, which the token scale never defined. The token is now 20 px, as in
  the mocks. This fixes the new datasource, new SLI, new SLO and datasource detail
  pages, and the agent detail cards.
- The SLI list has one action, the header's "New SLI", shown whenever the user
  can write; the empty state explains the prerequisite instead of adding
  "Create SLI" and "Add datasource" buttons.
- The SLO pages use the shared shell width (capped at 1240 px, centred) instead
  of an SLO-only full-width override, so text keeps the same distance from the
  navigation as on the other pages.
- A field-level error is not repeated as a second alert: the SLO target and the
  agent duration forms focus the invalid field instead.
- Real-journey regressions from the first round, which never ran before merge:
  product fixes for the New SLO form keeping the previous service and SLI, the
  agent name/status line alignment, and SLO detail status reasons overflowing a
  360 px screen; verifier updates where the product follows the shared controls
  (shared pager, status mark, detail heading, breadcrumb, collapsed runtime
  details, New SLI route to Add datasource, scoped chart lookups).
- Playwright test results live in a named volume: trace writes on the macOS bind
  mount failed with `EACCES` in four browser runs.

Not in this task: non-expiring agent credentials. SPEC-0004 limits agent
credentials to a 90-day default and a one-year maximum; removing expiry is a
security contract change that needs the maintainer's decision, an ADR and
backend work.
