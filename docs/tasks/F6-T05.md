## Outcome and non-goals

The datasource list, detail and create pages match `docs/design/mocks/ds-list.html`,
`ds-detail.html` and `ds-create.html` using today's API. Save intents,
idempotency, ETags, the uncertain-save reconciliation, reassignment handling,
readiness polling and diagnostics are unchanged.

List: page header (mono summary with the page's attention and moving counts,
Updated, Refresh, New datasource), toolbar (filter of the loaded page, health
segments All/Needs attention/Unused, agent select), the table with Health
(ADR-0028 datasource vocabulary from the agent's runtime and the reassignment),
Datasource (name, provider and endpoint, TLS unverified pill), Agent, Cadence,
Auth and SLIs, and the shared pager with a previous-cursor stack and 10/20
rows. Health and Agent columns need the agents read and so appear for
administrators only.

Detail: breadcrumb, title, status line, mono meta line, Refresh and Test
connection; Moving banner with its refresh/cancel actions; an unreachable-agent
banner linking to the agent; four tiles (Agent, Configuration from readiness,
Collection, Used by from the SLI list); Connection section (display name,
fixed identifier, provider card, endpoint, authentication segments with a saved
secret card offering Replace/Clear, Query every chips with a custom value,
TLS segments with the Custom CA textarea); Agent section (type-ahead with the
eligibility states); Test section (readiness status, PromQL editor, Run
preview, Cancel diagnostic, result); Discard changes and Save settings.

Create: Identity → Connection (provider cards with Tempo and Loki disabled)
→ Agent (type-ahead, connection test); Cancel or Back to SLI, Create
datasource, Create and add an SLI (continues to the SLI form with the
datasource preselected).

Out of scope, kept in the mocks: last query time/duration and last successful
test (no persisted diagnostic summary), the delete section (no delete
endpoint), the agent's datasource count in picker options.

Datasource vocabulary (ADR-0028 §3) from assignment and agent runtime:

| Condition | Tone | Label · reason |
| --- | --- | --- |
| reassignment pending | warning | Moving · A → B · waiting for A / B unavailable |
| agent connected | healthy | Healthy · agent connected |
| agent unreachable | stale | Not collecting · agent unreachable for N h |
| agent disabled | stale | Not collecting · agent disabled |
| agent never connected / no capabilities | none | Waiting · agent never connected / capabilities not reported |
| incompatible / no diagnostics | warning | Needs attention · reason |

Verifier label mappings (one-for-one): `Add datasource` heading/button →
`New datasource`; `Name` → `Identifier`; `Assigned agent` `selectOption` →
type-ahead option `#datasource-agent-option-<uuid>` or the selection summary
in the Agent region; `Polling interval (seconds)` → `Query every` chips;
`Custom CA PEM` is reached through the TLS `Custom CA` segment; `Back to
datasources` on the create page → `Cancel`, on the detail → breadcrumb link;
`Authentication` select → segments; `Bearer token secret`/`value` → the
`Token` input (new) or the secret card's Replace (saved); `Next page`/`First
page` → the shared pager.

## Acceptance and expected cases

- AC-11: side by side with the three mocks in both themes at 390/1440;
  recorded differences limited to deferred elements.
- AC-14: an unreachable, disabled or never-connected agent never renders the
  datasource as Healthy; a moving datasource is Moving in the list, the status
  line and the Agent column; secrets are never displayed.
- Validation and safety: identifier rule, uncertain create/save retry with the
  same key, cancel reassignment with the current ETag, retained-secret test
  guard, readiness-gated preview.

User acceptance checklist:

- `/datasources` with the fixture: four rows; Needs attention and Unused
  segments narrow the loaded page; the agent select filters; Refresh re-reads.
- Open the moving datasource: banner, tiles, disabled form, cancel/refresh.
- Open a healthy one: edit the display name, Discard changes; Replace the
  token; switch TLS to Custom CA; Save settings; Test connection; Run preview.
- `/datasources/new`: provider cards, agent picker with states, Create and
  add an SLI lands on the SLI form.
- Container deployment: the datasource and Compose journeys when the
  toolchain is available.
