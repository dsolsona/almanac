## Outcome and scope

An unwired backend adapter reads actual canonical observations/hourly sums into
the alert journal's exact evidence contract. Read binding, definition, source and
exclusion identities and every distinct condition window in one repeatable-read
snapshot. Use existing bounded Runtime admission and canonical batched windows;
do not add a raw fallback or a production scheduler registration.

Resolve the initial cutoff using canonical source settling/dispatch/completion
rules at the original scheduled boundary. Accept an explicit pinned cutoff on
retry; persist that pin before calculation, retaining it through deferral/reclaim
and clearing it only with committed advancement/cancellation. Pending aggregate
work returns the selected cutoff and no partial policy evidence. Explicitly
exhausted source aggregates produce `calculation_failed` evidence for affected
windows, while database failures remain work errors. Nonzero exclusions remain
explicitly pending until the
shared maintenance calculator is implemented; revision zero cannot silently stand
in for an existing mask. This is a bounded intermediate foundation, not AC-07
acceptance or usable public alerting.

## Acceptance and expected cases

- Real 99% SLO, 990/1,000 per minute: five-minute counts 4,950/5,000 and one-hour
  counts 59,400/60,000, exactly matching threshold 1; persisted journal fires.
- Multiple conditions share/deduplicate windows; all identities agree. Three
  custom conditions with six distinct durations are supported.
- Dirty interior preserves pending and chosen cutoff; no evaluation/occurrence
  or cursor advance. After preparation, retry reads every condition again.
- Missing, stale, complete-empty, zero traffic and full-window warmup cannot
  recover an open occurrence. Pending is never a window quality.
- A clock-only outage advances eligible cutoff without ingestion. Settling and
  dispatch remain canonical rather than an additional alert allowance.
- Evidence publication fences a concurrent source change; snapshot reads cannot
  mix generations. Reusing a pinned cutoff cannot move it on late arrival.
- A persisted maintenance revision rejects unadjusted calculation explicitly.
- Terminal aggregate failure leaves healthy conditions evaluable; unfinished
  preparation, including a leased final attempt, still defers the whole boundary.
- A different cutoff cannot enter the journal after pinning; administrative
  cancellation clears the pin and fences the cancelled worker.
