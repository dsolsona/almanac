## Outcome and acceptance

Agents, datasources and SLIs use the services table's bordered surface, typography,
density, centred values and mobile stacked rows. SLO pages remain unchanged.
Every column sorts ascending/descending across all filtered results before pagination.
Rows open their own detail; text selection, modifier clicks and inner links retain
their normal behavior. Names remain keyboard-accessible links.

Verify ordinary navigation and browser history, both themes, 360 px and desktop,
empty/error states, numeric sorting, unknown values and sorting records originating
on later API pages. Existing domain status and permissions remain in force.
The services page is the supplied visual acceptance reference for this amendment.
