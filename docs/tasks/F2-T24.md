## Outcome and non-goals

Deliver session-authorized credential management, dependency-guarded agent archival and readable durations across API, CLI and UI. The separately owned local launcher is excluded.

## Acceptance and expected cases

- Register Local with a 90-day credential; rotate with a ten-minute grace, then revoke without password proof.
- Open deletion for an assigned agent, inspect named datasource links and register a replacement; reassign every dependency and delete. All credentials stop authenticating and ordinary lists omit the archived identity.
- Reject stale versions, unauthorized and expired sessions. Preserve receipt replay and one-time-token behavior. Concurrent assignment and deletion cannot leave an assigned archived identity.
- Onboarding requests the new password after sign-in. Verify ordinary and invalid values, theme/mobile/keyboard flows, real database and container journeys.

## Interfaces and scope

`GET /api/v1/agents/{id}/datasources` returns a bounded `{items:[{id,name,display_name}],next_cursor}` page. `DELETE /api/v1/agents/{id}` accepts an empty JSON object and requires the current administrator session, CSRF, If-Match and idempotency key; assigned dependencies return `agent_in_use`, distinct from stale `conflict`. Successful lifecycle receipts replay after archival. Agent mutation requests contain no password proof. Generated API and SQL are regenerated from their sources.
