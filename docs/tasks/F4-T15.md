## Outcome and scope

Read current projection publication text once per scheduler scan instead of once
per candidate retained hour. Use a materialized CTE in `ReadDerivedDue` and
`ListDueDerivedObjectives`; regenerate their dbgen sources through sqlc. Preserve
all source/revision/cutoff/deadline predicates, retry budgets, leases, ordering,
limits and conditional timestamp parsing. No new schema, state, queue or pacing.

The accepted contracts require bounded background work without compromising
currentness or live ingestion. Equivalent query execution is an implementation
correction within those contracts and requires no new ADR. It does not itself
establish workload isolation or permit alert-engine adoption.

## Acceptance and expected cases

- A compatible current projection with unchanged retained history is not due.
- A newer covered hourly publication makes it due; publishing the corresponding
  cache marker clears that reason at the same evaluation boundary.
- Missing cache publication metadata retains its existing conservative refresh.
- A malformed marker is not parsed eagerly when an earlier source mismatch or
  failure/exhaustion branch determines the result; no new error behavior.
- Retry backoff and the existing ordered, bounded current-work selection remain.
- Empty fleets, expired current deadlines, source preparation before current,
  full-batch fairness and repair wakeups retain their existing regression cases.

User checklist: existing SLOs receive the same current/history refreshes and
staleness semantics; ingestion and navigation remain governed by their unchanged
budgets. There is no UI flow change. Normal-container full workload verification
remains a later primary-owned step after focused correctness and plan review.
