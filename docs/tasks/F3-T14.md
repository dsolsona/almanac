## Verification

On the microVM, `make test-smoke` populated the compiler cache and passed four
checks in 83.4 seconds, including 38 seconds in image builds. With a temporary
edit to the embedded HTML title, the next build produced a different app image
ID and took 4 seconds. All four checks passed again in 47.9 seconds end to end.
The title probe was reverted before publication. This exercises an edit with a
warm compiler cache, so the two runs have different cache conditions.

Image pin, documentation link and diff checks passed. The full benchmark and
broad suites were left to hosted CI. The [hosted smoke run][smoke-run] passed
all four checks in 29.7 seconds of Playwright time after 56 seconds of image
builds and 15 seconds of stack readiness. The broad jobs were skipped on the
smoke dispatch. The regular PR ran its four application suites.

The [regular end-to-end job][e2e-job] recorded a successful alert-policy create
followed by HTTP 503 from the policy list. The selected alert-policy journey
and onboarding passed locally in 46.5 seconds including deployment. The
reason for the CI response remains open. The other three PR suites passed.
