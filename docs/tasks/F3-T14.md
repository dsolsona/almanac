## Verification

checks in 83.4 seconds, including 38 seconds in image builds. With a temporary
edit to the embedded HTML title, the next build produced a different app image
ID and took 4 seconds. All four checks passed again in 47.9 seconds end to end.
The title probe was reverted before publication. This exercises an edit with a
warm compiler cache, so the two runs have different cache conditions.

Image pin, documentation link and diff checks passed. The full benchmark and
broad suites were left to hosted CI. Hosted smoke dispatch evidence is pending.
