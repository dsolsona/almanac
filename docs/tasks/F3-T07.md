## Implementation

The list/detail markup is ported from slo-tracker's `app-list-row.tsx`,
`list.tsx` and `app-detail.tsx`. Their `app-list.css`, `app-detail.css` and
Almanac theme rules are retained in `web/src/slos/slo-reference.css`, with adapters
for Almanac's shared controls and real API records. The list uses the source
104px/status, flexible/name, 160px/history, 104px/budget, 78px/burn and 90px/exhaustion
columns. The detail uses a 150px label column and 162/202/202/142px numerical lanes,
with the source chart insets and a 340px table slot. Narrow layouts follow the
source's label/plot arrangement rather than the former metric-card redesign.

The reference's compact number formatting is used for reading; exact decimal
strings remain in table values and metric titles. Tables use the source
Time/Value/Good/Total/Samples/Coverage composition, with completed-day identities,
effective evaluation times and window qualification for compliance. Unknown and
not-applicable outcomes remain distinct.

The SLI read generates at most twelve explicit integer slots instead of using a
dynamically bounded timestamp series. The start/end arithmetic, settling delay,
retention, activation and observation precedence remain unchanged. No new cache,
public API or database migration is introduced.
