## Acceptance checklist

1. An administrator selects Prometheus, VictoriaTraces, Tempo or Loki, enters its
   endpoint and authentication, and selects an agent capable of that provider.
2. The assigned agent tests the connection and previews bounded aggregate queries;
   backend execution never contacts the source. Old agents cannot accept unsupported work.
3. An editor creates a good/total event-count SLI with language and interval guidance.
   Persisted source observations feed the existing SLO budget/burn calculations.
4. Invalid queries, multiple series, incomplete responses, missing components and
   fractional counts never create successful observations. Secrets remain redacted.
5. Optional local source services support an isolated real collection journey.
6. Verify light/dark desktop/mobile, keyboard entry/correction and provider changes;
   attach final datasource-create renders to the PR.
