## Outcome and scope

Within the caller's existing snapshot, check the first window's canonical interior
readiness before calculating a batch. Reuse `derivedWindowBatchParams`; exhausted
source returns the existing failure before pending. A ready first window executes
the unchanged canonical batch and preserves ordinal evaluation/error precedence.
Empty input remains an empty result without database work. Source scheduling,
two-second deferral, batch limits, public results and canonical SQL output are unchanged.
