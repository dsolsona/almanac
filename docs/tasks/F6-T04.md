## Outcome and non-goals

The New SLI and New SLO pages match `docs/design/mocks/sli-create.html` and
`slo-create.html` using today's API, composed from numbered form sections.

New SLI: page header with breadcrumb and mono summary; Identity (display name,
identifier suggested from it); Source (datasource type-ahead with the agent's
reachability for administrators, collapsing to a selection summary, "Add a
datasource" when nothing matches); Measurement (segmented kind in the section
heading with the two unavailable kinds disabled, side-by-side PromQL editors
labelled Good events and Total events, footnotes); actions Cancel, Create SLI and
Create SLI and add an SLO, which continues to `/slos/new?sli=<id>`. Field
errors appear under their controls and in one summary alert.

New SLO: Identity (display name, identifier, service type-ahead whose no-match
action opens the existing two-step inline service creation); Indicator (SLI
type-ahead with the ADR-0028 SLI vocabulary, datasource, cadence, linked
objectives and sample age; preselected from `?sli=`); Objective (target and
rolling-window chips with a self-applying custom value, the historical
checkbox); Alerting as a muted placeholder; actions with the mono note.

Shared: `FormSection` and `FormActions` in `web/src/components/ui/`, demonstrated
in the catalogue; SLI vocabulary moved to `web/src/slis/vocabulary.ts` so the SLO
picker reuses it.

Out of scope, kept in the mocks: description fields, the "queries return" units
toggle, the query test panel, the budget preview, the SLO edit page with
revisions (needs the revision contract), minutes/hours/weeks windows (the mock
and ADR use whole days).

## Acceptance and expected cases

- AC-11: side by side with both mocks in both themes at 390/1440; recorded
  differences limited to deferred elements.
- AC-14: picker options and summaries never show an unreachable or unreported
  agent as healthy; a waiting SLI is selectable and labelled Waiting.
- Keyboard: chips are one tab stop per group with arrow selection; pickers open
  on focus, arrows move, Enter selects, Escape closes, Change restores focus.
- Validation: empty fields are reported under their controls and in the alert;
  100 % target and non-integer days are rejected before any request; window
  alignment to the SLI cadence is still checked in seconds.

User acceptance checklist:

- `/slis/new` with several datasources: type part of a name, see the state of
  each option, pick one, Change it; submit empty to see the field errors;
  Create SLI and add an SLO lands on the SLO form with the SLI preselected.
- `/slos/new`: type an unknown service name, create it inline, pick an SLI, use
  a custom target and window, apply to earlier measurements, create.
- Reference comparison: `sli-create.html` / `slo-create.html`.
- Container deployment: the real SLI and SLO journeys when the toolchain is
  available.
