## Outcome and non-goals

Local bootstrap/run starts persistent VictoriaMetrics and VictoriaTraces alongside
the app. A separate isolated acceptance check writes synthetic metrics and OTLP
spans and verifies actual Prometheus and TraceQL metrics queries. This supplies test
sources, not implemented Almanac providers or advancement of the F6 milestone.

## Acceptance

- Real Prometheus query returns the inserted value at expected timestamp(s).
- Real TraceQL metrics query returns measurements derived from inserted spans;
  test series and numeric content, not merely HTTP200 or nonempty JSON.
- Failed HTTP/invalid responses fail the gate; bounded readiness/indexing waits.
- Existing Compose startup/onboarding/cleanup suite remains compatible.
- Test cleanup leaves default app, preview and integration database untouched.
