## Implementation

Pinned standard SDKs own W3C propagation and OTLP/HTTP export: Go OTEL 1.47.0,
browser SDK 2.12.0/API 1.9.0/exporter 0.223.0. Instrumentation covers browser
navigation/fetch/body/parse/chart/font/paint, HTTP/auth/services/encoding, separate
pool acquisition and named SQL, calculations, background admission/execution,
agent configuration/heartbeat/provider/ingestion and CLI calls.

The fixed same-origin browser intake retains normal session, origin and CSRF
checks. It accepts at most 128 KiB and 64 spans, admits at most 60 requests per
session/minute with 256 tracked sessions, sanitizes fixed names/attributes and
never exposes exporter credentials or proxies to a browser-selected destination.
Intake work is excluded from owned tracing without bypassing authentication.

Go export uses a 2,048-span queue, 256-span batches, 250 ms scheduling and two-second
network/shutdown bounds. Internal metrics expose queue occupancy, drops and export
failures. Browser replay is bounded to five minutes, 128 spans/128 KiB and
48 KiB batches; it is tied to the authenticated user and cleared on sign-out/user
change. Export/replay is independent of navigation. Raw queries, SQL parameters,
credentials and arbitrary error bodies are excluded.
