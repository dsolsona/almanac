## Acceptance

- A datasource administrator can enter whole days of source retention or leave
  it unknown. Previous clients omitting the setting preserve the stored value.
- An operator can open historical gaps from an SLI's Measurements section,
  see exact missing durations and distinguish automatic from manual jobs.
- Confirming a preview queues only eligible, uncovered intervals in bounded
  batches. The same recovery cutoff applies to manual requests and repair.
- Accepted history recalculates linked SLOs through the canonical ingest path.
  Render the approved workflow with existing SLI detail controls and layout.
