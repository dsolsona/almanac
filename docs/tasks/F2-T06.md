## Routes and requests

| Route | Service | Success |
| --- | --- | --- |
| GET /api/v1/agents | List | 200 AgentPage |
| POST /api/v1/agents | Create | 201 fresh, 200 replay; AgentIssuance |
| GET /api/v1/agents/{agent_id} | Get | 200 Agent plus strong ETag |
| GET /api/v1/agents/{agent_id}/credentials | Credentials | 200 CredentialPage |
| POST /api/v1/agents/{agent_id}/disable | Disable | 200 LifecycleResult |
| POST /api/v1/agents/{agent_id}/credentials/rotate | Rotate | 200 RotationIssuance |
| POST /api/v1/agents/{agent_id}/credentials/{credential_id}/revoke | Revoke | 200 LifecycleResult |

No route renaming/aliases. Canonical UUID IDs only. Unknown route404; unsupported
method405 with appropriate Allow; HEAD is not implicitly supported by GET routes.
Every managed response/error has no-store,nosniff and generated X-Request-ID.
No caller RequestID passed through as authoritative ID. Reject Authorization header
with401: local session cookies are the only supported authority in this increment.

GET list accepts singleton limit and cursor only: omitted limit50, canonical integer
1..200; storage validates cursor. Detail accepts no query. Reject unknown/duplicate
query fields, GET positive Content-Length or Transfer-Encoding. GET rejects supplied
If-Match/Idempotency-Key. POST accepts no query; one Idempotency-Key1..128 ASCII33..126
mandatory. Preserve comma as part of a single key; reject duplicate header fields,
do not split key as a comma-list. Existing auth idempotency rejection remains501.

Existing-target POST requires exactly one strong If-Match
`"agent:<URL-agent-canonical-uuid>:<canonical-positive-int64-version>"`.
Missing/malformed=>400 invalid_request. Reject weak tags,*,lists,duplicates,wrong
agent,signs,leading zeros,zero,overflow/internal whitespace. Create rejects If-Match.
No body version. Parse with signed64 decimal, pass directly to service; do NOT read
current version first, because storage replays historical receipt before target
version checks. Valid stale version409. Detail GET alone returns this ETag; no
collection/mutation ETag, conditional caching or304 work. A replay version is historical.

POST media/body boundary: application/json with optional UTF-8 charset, no
Content-Encoding,4096-byte endpoint cap, actual5-second read deadline and bounded
body read. Reject duplicates,unknown members,trailing JSON,wrong types,missing/null
required members; optional null also invalid. Existing json/v2 strict decoding is
suitable, but auth decodeObject's exact-member-count helper cannot directly handle
optional fields. Use small endpoint-specific wire structs/mapping, not generic schema
middleware. Preserve ResponseController access through wrapper Unwrap.

Bodies: Create requires current_password,name,display_name; optional lifetime_seconds.
Rotate requires current_password; optional lifetime_seconds,overlap_seconds.
Revoke/disable require current_password only. No actor/proof/session/verifier or
candidate credential material in body. Seconds are bounded JSON integer tokens:
lifetime omitted/0=>90days, otherwise1..31536000; overlap omitted=>600, explicit0..600.
Reject exponent/fraction/negative/overflow forms and validate before Duration
multiplication. Bounded seconds use generated int32/JS integers. Preserve existing
password/name/display validation; no text normalization.

## Generated DTOs and fixed errors

API DTOs are separate from storage structs. Use source OpenAPI generation only.
Agent fields: id,name,display_name,enabled,version,created_at,updated_at.
Credential: id,agent_id,issued_at,expires_at,revoked_at,retire_at; last two explicit
nullable timestamps. Create maps its issued metadata to null retirement/revocation.
Page: items nonnull array,next_cursor string(empty=end). LifecycleResult:
agent,credential(nullable),changed,revoked_credential_count,replayed.
AgentIssuance: agent,credential,replayed,secret_state,conditional token.
RotationIssuance adds previous_credential(nullable).

Version is canonical positive-decimal JSON string bounded to MaxInt64;
revoked_credential_count is canonical nonnegative-decimal string. Generated TS must
use string, not number/int64 format. No float conversion. UTC RFC3339 microsecond
timestamps. No epoch/verifier fields. Preserve historical replay metadata, never
replace it with a fresh current-state read.

secret_state only issued or secret_unavailable. Fresh requires false/issued and
nonempty token; replay requires true/secret_unavailable and token member absent.
Use explicit one-time DTO construction; retain internal Token json exclusions.
Use the smallest generator-supported OpenAPI variants that express this invariant;
no generator upgrade or new serialization framework. Test actual JSON presence.
No secrets in ordinary reads/errors/headers/Location/logs/traces/diagnostic dumps.
No automatic retry or token retrieval. On service error/ambiguous commit return no
candidate; response write failure after commit cannot undo or repeat the command.

Reuse Problem shape, with fixed messages/codes and field_errors array. Map boundary
and service/storage sentinels explicitly:400 invalid_request for grammar/shape;
401 unauthenticated for invalid session/password/expired proof;
403 forbidden for role/restriction plus existing distinct origin_rejected,
secure_transport_required,csrf_invalid;404 not_found after authority;
409 conflict;422 invalid_agent_input for decoded semantic input failures;
429 rate_limited with positive ceil-seconds Retry-After;
408 request_timeout,413 request_too_large,415 unsupported_media_type;
503 management_unavailable for remaining readiness/dependency/internal errors.
Never print err.Error into Problem or inspect target existence before authorization.
Disconnected/cancelled clients may receive no body; don't manufacture success.
