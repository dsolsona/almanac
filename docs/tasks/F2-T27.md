## Outcome and acceptance

Reassign a datasource serving SLIs while preserving interval identity, history and unaffected schedules. Pending source and target remain deletion dependencies. A live source acknowledges only after cancellation and drain; an offline source waits until its recorded authority expires. A bounded background reconciler atomically cuts ownership at a canonical interval boundary, after checking target capabilities. Versioned cancellation restores source scheduling. Expose waiting and unavailable replacement state and reject incompatible pending edits.

Prove online drain, offline expiry, old buffered results, target cutoff, unrelated grants, deletion races, cancellation and target failure with real database and agent tests. UI and CLI explain pending state and permit cancellation; coordinator independently verifies the real user journey.
