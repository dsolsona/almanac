## Outcome and non-goals

The SLI list and SLI detail match `docs/design/mocks/sli-list.html` and
`sli-detail.html` using today's API. The create form is unchanged here (F6-T04).

List: page header (title, mono summary with the loaded page's attention count,
Updated, Refresh, New SLI), toolbar (search with `/`, datasource select), the
dense table with Health (status mark plus reason), SLI (display name link with
the mono identifier), Type, Datasource, last 12 intervals strip with its exact
table, Last sample (ratio, time, counts), SLOs (links, "+n more", inline Create
SLO when none), and the shared pager.

Detail: breadcrumb (kept per SPEC-0012), title, status line, mono context,
actions (Refresh, Edit SLI dialog, New SLO); four tiles (latest result, last
good ratio, collection state, loaded history); a measurements chart from the
loaded observation rows with an exact table; the recent-intervals table with a
loaded-rows outcome filter, missing-interval and retention notes and Load more;
a Definition card (datasource, agent, cadence, activation, next query, both
queries); an Objectives card from the list projection; technical identifiers in
a collapsed disclosure.

Out of scope, kept in the mocks: description; a server-side health filter and
global attention counts (list has no health parameter); chart range chips and
volume bars (no bounded range read; chart lane allows one series here);
objective status on the Objectives card (linked SLOs carry names only);
editing queries (immutable from this screen).

| otherwise | healthy | Healthy · agent connected |

## Acceptance and expected cases

- AC-05: agent reachability, collection progress and freshness remain separately
  visible on the detail (collection tile and chips) and the reason line never
  substitutes one for another.
- AC-06: the measurements chart and its exact table are built from the same
  loaded observation rows; failed and incomplete intervals are gaps, zero
  traffic is explicit, no value is fabricated.
- AC-11: side by side with both mocks in both themes at 360/1024/1440.
- AC-14: missing, stale, zero-traffic and no-data states stay distinct in the
  list reason line, the tiles and the table.

User acceptance checklist:

- `/slis` with the fixture: ten SLIs; the summary counts the page's attention
  rows; search filters through the URL; the datasource select filters.
- Open a row → detail: tiles, chart with loaded rows, table, definition,
  objectives; Load more extends chart and table; outcome filter narrows the
  loaded rows; Refresh re-reads; breadcrumb returns to the list.
- Edit SLI → dialog; empty name → inline error; valid → title updates.
- Reference comparison: `sli-list.html` / `sli-detail.html`.
- Container deployment: the real SLI journey (`check-sli-browser.mjs` via the
  integration lane) when the toolchain is available.
