## Interfaces

- `make bootstrap`: `docker compose build`, then invoke the same start path as run.
- `make run` (alias `make start`): `docker compose up -d --wait --wait-timeout 90`,
  then show URL https://localhost:18088, admin login, and `make credentials` instruction.
  No host build/install. Absent images explain bootstrap; no implicit host tooling.
- `make stop`: `docker compose stop`; never down -v or reset.
- `make logs`: logs from app only, without exposing secrets.
- `make credentials`: explicit one-time-password retrieval from the secrets volume
  through app container, warn it is only the initial password and never current
  after rotation. No password printed by bootstrap/run/container logs.
- Default Compose project `almanac-local`, support Compose's ordinary
  COMPOSE_PROJECT_NAME for isolated acceptance. App host mapping
  `127.0.0.1:${ALMANAC_PORT:-18088}:8080`, matching public origin's port. No DB host port.
  Reject or safely fail malformed port overrides; no command interpolation/eval.
