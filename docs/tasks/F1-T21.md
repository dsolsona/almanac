## Outcome and edit scope

A reproducible dependency base, independent CoW worker disks, authenticated/trusted
Codex, guest-only Docker, GitHub capability and named lifecycle commands. Script,
focused Python tests, discoverable Make help, targets and affected documentation only. No Go changes,
application behavior, memory snapshots or pane orchestration.

## Acceptance and expected cases

- Build a base once; rebuild without changing existing workers.
- Launch two workers with inline/stdin prompts and independent dirty source
  snapshots; inherit Docker images/dependencies without another `make setup`.
- Confirm fresh SSH/machine identities, Docker/code isolation and distinct PR branches.
- Authenticate Codex, execute its tools, run containers and reconnect to its terminal.
- Transfer GitHub login privately; configure HTTPS origin and Git author identity.
  Verification must not push or open an unsolicited PR.
- List running/stopped/partial workers; stop/start without losing work; delete one
  explicitly named disposable worker while preserving other VMs and shared bases.
- Reject stale dependencies, unsupported CoW, active seed tasks, unsafe paths,
  unknown PIDs, partial images and failed shutdowns while preserving data.
- Preserve prompt bytes through Bash and Make, including shell/Make metacharacters.
- Generate and print a random two-word name for unnamed setup/run/base calls;
  reserve names atomically and preserve explicitly named workers on collisions.
- Explain interactive task input before waiting; expose every public Make target
  in grouped help with descriptions, useful options and examples before setup.
