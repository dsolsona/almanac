## Bounded calculation proposal and next experiment

On 2026-11-13 the maintainer authorized updating the drafts to investigate bounded
raw calculation as the preferred candidate. This replaces the unconditional wait
proposal with an experiment gate; it does not accept the architecture or authorize
production engine implementation. ADR-0051 compares waiting, independent condition
processing and bounded fallback. SPEC-0020 contains the proposed shared-calculator
amendment; ADR-0040 has a reciprocal proposal note and remains accepted unchanged.
SPEC-0021 retains complete ordered policy decisions and durable pending work when
fallback cannot finish. SPEC-0022 distinguishes calculation delay from source quality.
The five-minute closed-hour target is correctly identified as chart-extrema work,
not source aggregate preparation or an inevitable hourly alert pause.

Next work is the focused calculation experiment specified in SPEC-0021, before
engine implementation. Its outcome must be a reproducible comparison and adoption
recommendation, not a production state-machine claim:

- [ ] Pin the runner, candidate revision, numerical dirty-hour/raw-row/time/concurrency
  budgets and focused Docker commands before measurement; use isolated fixtures.
- [ ] Prove per-SLI query equivalence against an independent canonical-observation
  reference: clean/mixed/dirty interiors, cadence/hour edges, quality/null totals,
  exclusions/revisions, concurrent updates and budget deferral without partial totals.
  Record unsupported semantics rather than claiming them tested.
- [ ] Run one 200-SLI contention comparison across rollover with multi-day backfill
  flooding the dirty queue, live ingestion and the default alert-window query mix.
- [ ] Report rows, query duration, fallback/deferral frequency, incomplete requests
  and interference with ingestion/SLO navigation; pin runner and load inputs.
- [ ] Review results and calculation limits with the maintainer; use them to propose
  an end-to-end target for later engine verification. Preserve failures if unsuitable.
