## User acceptance

- Available collection capacity is reused when work completes, without an artificial
  one-second wait for each batch. Configuration and valid authority updates promptly
  wake scheduling; they never bypass a grant, revision, clock or lease check.
- Under 100/1,000 due definitions, active work stays within eight evaluations per
  agent and four per datasource. Fair admission prevents a fixed configuration order
  from monopolising slots across datasources or repeated collection windows.
- With cadence 60 seconds and settling 60 seconds, an expired pending endpoint
  12:42 at clock 12:44 must not cause the eligible endpoint 12:43 to be skipped.
  Its query still evaluates at 12:43 and covers 12:42–12:43. It never reads an
  unsettled interval, creates a partial interval, backdates activation or invents zero.
- Expired intervals remain visible as missed collection through the existing loss
  reporting mechanism. State and catch-up are bounded; no unbounded historical
  queue, implicit backfill or interference with the historical-work channel.
- Cancellation, configuration drains, agent shutdown and unchanged live cursors
  retain existing guarantees. Deterministic tests use explicit time and controllable
  completions instead of minute-long sleeps or optimistic throughput claims.
