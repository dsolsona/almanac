## Outcome and non-goals

Pixel-parity implementation of approved refined B using real operational values.
No API, schema, calculation-policy, provider or alerting changes. The backend asset-preload declaration follows the new bundled SVG route.

## Interfaces and edit scope

Existing `sloClient.current` / `operational`, their cancellation and validated
response types; shared UI and chart components; detail stylesheet, focused tests,
catalogue, accepted reference and guidance. No generated source changes.

## Acceptance and expected cases

- Signed-in user opens list → SLO detail: compact verdict, integrated budget
  summary/plot, burn, attainment and completed days; disclosures start collapsed.
- Target .999, total 10,000,000 and bad 8,200 give 10,000 allowance, 1,800 left,
  18% remaining and 99.918% attainment. Backend results are authoritative.
- Bad 12,000 preserves −2,000 and −20%; incomplete coverage labels observed-only
  values and unknown performance, independently of freshness and urgency.
- Hover/keyboard/touch expose exact response values/timestamps; gaps have reasons,
  no invented points. Legend matches day blocks in both themes.
- Refresh/range/burn/timezone, rename, browser history, linked SLI and access-denial
  recovery retain existing behavior. No table controls or empty exact section.
- Compare all panel geometry, typography and colors against B at 360/1024/1440 px
  in light/dark. Review controls are not product content.
- Real isolated deployment verifies persisted SLO counts and navigation;
  performance checks measure usable plots, first visits and changed ranges.

## Post-merge dense-history correction

Maintainer reported that a 30-day budget graph was obscured by hollow sample
markers and an overlaid inspection card. On main `7ed0a06`, each qualified sample
becomes an isolated 8 px-wide hollow circle, even when adjacent timestamps are
less than 2 px apart. Reproduction uses 720 hourly samples with a 20-hour gap.
Acceptance: retain the true gap and exact partial/missing inspection, keep the
trend readable at 360/1024/1440 px in both themes, and place inspection details
below the SVG so they cannot obscure the plot. No interpolation across unknown
values or changes to backend classification/calculations.

The shared chart uses thin, density-bounded horizontal marks for isolated samples
and places inspection details below the plot on every pointer type. One selected
point still has its crosshair and inspection marker. Existing complete-data
geometry remains unchanged. The catalogue's partial/observed/missing example uses
these actual shared states.

A unit regression first failed against the hollow circles (five existing cases
passed). After correction all six unit cases pass in 1.22 s and TypeScript passes.
Thirteen existing browser cases pass, preserving all 18 zero-pixel chart reference
comparisons. The first new browser matrix used inconsistent completed-day records
for its extended 30-day range and was correctly rejected by API validation; the
fixture now supplies all 30 days. All six corrected dense-history browser cases pass in 1.0 min, including
keyboard inspection of the missing gap and non-overlapping details. Local screenshots are `.local/slo-density-*.png`. This focused
rendering change does not claim renewed native-container or performance evidence.
