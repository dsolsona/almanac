What is this agent?

An agent is a small process you run inside your network. It pulls its configuration from Almanac and runs the SLI queries against your datasources, so nothing in Almanac needs inbound access to your metrics.

Where it runs: a region, cluster or host.
Used in the API and CLI. Fixed after registration.
The agent stops authenticating when the credential expires. You can rotate it any time from the agent page; Almanac warns a week before.
