SLI table

  • Exact values leave the table. The strip stays as the at-a-glance view; exact counts live on the SLI detail page, where the disclosure has room.
  • Last sample: one value, the good ratio and its age ("99% · 2 h ago"). The counts and the exact UTC time move to the tooltip, so the header no longer needs "UTC".
  • SLOs: a count ("6 SLOs") that links to the SLO list searched for this SLI, with the names in its tooltip. It reads the same with 1 or 50 SLOs. With none, it offers "Create SLO". No chips: they would not fit five names and would compete with the health chip.
  • Health names the data, not a verdict: an SLI is a measurement; only its SLOs judge it. Up to date, Stale, Waiting for data, Query error, Partial data, Zero traffic replace Healthy, Not reporting, Waiting and Failing (ADR-0028 decision 3 is amended).
  • SLI column: the display name and only its datasource. The identifier repeats the name and every SLI is a ratio today, so both go (they stay on the detail page).

SLO table

  • Status: the chip only. The reason ("observations stale · +4 more") moves to the chip's tooltip and the detail page; the group heading already says why rows are here.
  • Objective replaces "Target · window": one value, "99.9% · 30 d".
  • Budget · 7 d and Budget left replace "Budget · last 7 d" and "Remaining": the trend chart has its own column and starts under its header; the current value follows in its own column.
  • Column spacing: each column is as wide as its widest item, and every column has the same side padding, so neighbouring columns are always the same distance apart. The name column takes the remaining width.
  • Alignment: the name column is left-aligned; every other column is centred, so its header, chips, values and graph share one centre line between the column boundaries.
  • Burn rate replaces "Burn 1 h · 6 h": the one-hour rate only; the six-hour rate is in its tooltip.
  • Budget runs out replaces "Exhaustion": when the budget would run out at the current rate ("in ≈ 2 h", "exhausted"), or "—" with the reason in the tooltip. No second caption line.
  • Selecting text: rows stay clickable, but the whole-row link overlay goes. Clicking anywhere opens the SLO unless text was selected or a link inside the row was clicked; the name stays a real link for keyboard and middle-click.

Focus

  • Text inputs and selects show one accent border on the field itself instead of a 3 px ring offset around the wrapper. Buttons and links keep the outline ring, which keyboard users rely on.
